## 实际演练过程

```text
稳定实例与全新测试数据卷
    → 拒绝无数据卷的错误配置
    → 准入健康候选实例，并验证网关实际选择
    → 受控候选实例写入
    → 第三次采样前暂停候选实例
    → 两次失败采样 → 一次回退
    → 稳定实例持续健康 → 事件恢复
    → 解除暂停 → 独立恢复观察窗口
    → 再次拒绝错误配置 → 清理资源
```

稳定实例和健康候选实例使用**同一个不可变镜像**，每次演练共享一个全新测试数据卷。
错误数据库路径实例不挂载任何数据卷。
网关只在本机回环地址提供读取流量；明确的测试写入使用资格配置绑定的
Alex Chen / Sam Rivera 名单。

由所选发布实例返回的网关响应证明提升和回退，不以候选实例自身端点健康代替。
暂停前确认真实受控写入已经发生。每次演练写入后的完整行与结构哈希
都与回退后的哈希相同，且与更早的哈希不同。

## 实测观察

| 指标 | 第一次 | 第二次 |
|---|---:|---:|
| 监测采样数 | 10 | 10 |
| 健康／失败采样 | 8 / 2 | 8 / 2 |
| 短窗口健康比例 | 0.8 | 0.8 |
| 首次失败观察后的检测时间 | 4,212 毫秒 | 4,210 毫秒 |
| 事件打开后的恢复确认时间 | 773 毫秒 | 793 毫秒 |
| 采样事件跨度 | 4,985 毫秒 | 5,003 毫秒 |
| 回退次数／已恢复事件数 | 1 / 1 | 1 / 1 |
| 独立健康恢复采样数 | 5 | 5 |
| 再次拒绝错误配置 | 是 | 是 |
| 已清理容器／全新数据卷 | 3 / 1 | 3 / 1 |

两次使用不同的事件、证据标识和全新数据卷。第二次是明确记录的独立重复，
不是隐藏重试或覆盖第一次结果。采样跨度**不等于连续停机时间**，
这些数据也不是生产 MTTR 或 SLO。探测超时会影响观察到的检测间隔。

## 维护仍需审查

本次原因已知：操作者故意暂停候选实例。
严格准入检查已经存在，两次演练都在恢复前后拒绝错误配置。

自动生成的维护草稿**尚未批准**。其中通用的“原因未确认”和“实现缺失的检查”
不能作为本次实验的事实诊断。启动新的交付前，应审查已知注入、现有检查、
责任人和确有依据的后续工作。服务恢复本身不会批准维护规格，也不会关闭预防工作。

## 尚未证明的内容

- 未测试跨版本发布、数据库结构回滚或生产灰度。
- 只读网关和受控写入不能证明通用的并发写入安全。
- 有限的短窗口采样不能认证长期可用性或就绪检查的锁等待期限。
- 八项基线依赖告警仍然存在；功能验收不是生产认证。
- 演练容器、全新数据卷和回环网关均已清理；截图地址不是在线部署。

## 怎样讲解或重复

先展示准入拒绝，再展示网关选择、两次失败观察、一次回退和写入保留哈希。
最后说明维护审查边界，不宣称已经自动完成预防措施。
