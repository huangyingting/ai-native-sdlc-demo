# 工程判断演示工具包

[English](README.en.md)

这是一个基于 Node.js 24 实现的零外部依赖工程工具包，专门服务于以下三项紧密关联的工程实践演练：

1. **变更影响分析**：生成结构化提案、执行显式架构评审，并产出向后兼容的代码实现。
2. **根因归因诊断**：基于客观测试报错现场，精准区分业务代码、测试框架或环境配置层面的故障。
3. **Agent 策略对比**：基于标准化案例，量化评估 Copilot 的“直接生成修复”与“先诊断再生成修复”两种策略在质量与成本上的差异。

演练操作请参阅[工程实验分步演练指南](https://github.com/huangyingting/ai-native-sdlc/blob/main/docs/guides/engineering-judgment-demos.md)。
用于实验的独立应用位于 [`demos/engineering-lab`](../../demos/engineering-lab)。该应用与服务台生产代码完全解耦，其运行不会影响此前任何生命周期的交付审计证据。

```sh
npm run demo:engineering -- --help
npm run test:engineering-demo
```

离线测试不会调用 Copilot API。真实执行指令会显式调用本地已安装并认证的 GitHub Copilot CLI，并消耗实际模型配额。工具绝不擅自篡改已配置的模型；所有度量指标均如实记录实测观察到的模型名称与计费单元。

<a id="boundaries"></a>
## 严格的安全隔离边界与评测规范

- **零提示词信息泄漏**：仅有已提交的测试基底文件与真实的测试报错日志会进入 Prompt 上下文；严禁将高可信的验收判定器代码或预设的故障分类标签发送给模型。
- **严格工具隔离**：在评测中，Copilot 无法使用任何文件系统、Shell、网络或 GitHub API 工具。模型仅负责返回结构化的候选文本，由路径白名单适配器安全应用文件变更。适配器显式排除了所有 CLI 工具集，并严格校验结构化遥测日志中记录的“可用工具数”与“工具请求数”均为 0。对于已测试的 CLI，仅传入空的 `--available-tools=` 参数**并不足以保障安全**。任何遥测数据缺失或非预期变动均直接视为异常中断，杜绝在未经验证的情况下假定隔离有效。工厂工具与动态工作流别名均被显式排除；任何工具集变动均需重新跑通资格核验。被拒绝的调用会如实记录为独立失败，严禁在实验单元内隐蔽重试。
- **无损事件解析**：响应内容直接从 CLI 结构化事件流中无损解析。普通终端渲染可能会对 JSON 字符串进行换行折叠；适配器坚决不主观猜测或篡改修复。
- **容器纵深防御**：生成的候选代码仅在非 root 用户、完全隔离网络、工作区与判定器设为只读、严格限制内存/CPU 资源的 Docker 容器内编译执行，仅开放临时可写存储。这是针对已授权实验的纵深防御机制，不替代全方位的生产安全认证。
- **公平无偏对比**：每个策略与案例均输入相同且干净的代码现场与故障输入、相同的独立验证程序，并受到最多 2 次调用（单次限时 120 秒）的严格预算约束。直接策略使用 1 次调用，先诊断策略使用 2 次调用。严禁通过自动化重试或人工介入修补来美化单个实验数据。执行截止时间严格覆盖沙箱启动与代码验证全过程；有界清理逻辑单独计时，且必须在报告成功前彻底完成。
- **真实记录客观结果**：无论是候选代码崩溃还是虚假完成声明，均如实作为实验结果存档。基准流程跑通绝不等于代码修复成功。
- **精确度量而非盲目估算**：缺失的用量记录为 null，而非 0。高级请求单元（premium-request）与 nano-AIU 字段是 CLI 真实报告的客观度量单位，不作为实际账单的美元估算。
- **方案哈希强绑定**：人工审批必须严格绑定方案与测试基准的内容哈希。它属于本地操作者的审计回执，不代表 GitHub 官方认证或独立第三方的业务验收。
- **本地纯只读安全保障**：工具包在运行中绝不向远程仓库推送提交、触发工作流、创建 Issue 或批准任何 PR。

私有提示词原文、完整对话历史与执行细节统一保存在独立的外部实验目录中。公开归档前须经过安全脱敏审查；公开的汇总报告仅包含实测度量指标与文件哈希，不公开候选源码载荷或原始未脱敏日志。
